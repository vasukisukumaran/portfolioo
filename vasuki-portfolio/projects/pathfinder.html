PATHFINDER

Career Guidance Chatbot

Project brief

The idea.

For a student exploring careers, a useful starting point is what they already enjoy and do well. PATHFINDER uses a conversational interface to connect those interests and skills with possible career directions.

Technology stack

  • Python
  • Tkinter

How it works.

  1. Start a conversation

    The student interacts with the chatbot through a Tkinter desktop interface.

  2. Explore interests

    The conversation draws on the student's interests and skills.

  3. Consider directions

    The chatbot helps the student explore career options related to that input.
