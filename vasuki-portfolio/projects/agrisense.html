AgriSense

Smart Agriculture Management System

Project brief

The idea.

Choosing what to grow and how to nourish it starts with the soil. AgriSense brings both decisions into one web application, so a grower can use the same soil information to explore crop and fertilizer recommendations.

Technology stack

  • Java
  • Spring Boot
  • MySQL
  • HTML
  • CSS
  • JavaScript

How it works.

  1. Soil information

    The soil details provide the starting point for a recommendation.

  2. Crop selection

    The application recommends crops based on those details.

  3. Fertilizer guidance

    The grower can also see fertilizer recommendations for the soil.
