Smart Vehicle Parking

Smart Vehicle Parking Management System

Project brief

The idea.

Knowing whether a space is free depends on knowing which vehicles have arrived and left. This application connects vehicle movement with slot availability, bringing both into one parking management system.

Technology stack

  • Java
  • Spring Boot
  • MySQL
  • HTML
  • CSS
  • JavaScript

How it works.

  1. Vehicle entry

    The system manages vehicles entering the parking area.

  2. Slot availability

    The application displays available parking spaces.

  3. Vehicle exit

    Departure information helps the system keep track of available slots.
